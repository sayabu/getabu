Primary action control; use for every CTA so yellow stays the single "do this" signal.

```jsx
<Button variant="primary" size="lg" elevated href="/learn">Start Learning</Button>
<Button variant="secondary" href="/work">Work with me</Button>
```

Variants: `primary` (sun on light or dark), `secondary` (hairline outline), `invert` (ink fill — used inside yellow bands), `ghost` (ember text link with arrow). Never put yellow text on paper.
