# getabu.com website kit

`index.html` is the full homepage on the Signal Bright base — the reference assembly of every component in this system.

Band order and what each one is for:

1. **Header** — logo mark, four links, one yellow CTA.
2. **Hero** — eyebrow, display H1 (max 560px), lede (max 480px), primary + secondary buttons, photo slot with credential pills. Two blobs, both partly off-canvas.
3. **Free tutorials** — three `TutorialCard`s; the third is the sun-yellow flagship.
4. **PXPI band** — the only inverted band on the page. Ink surface, ember blob, `EmailCapture` on the right.
5. **Recent writing** — three `PostCard`s, image tones cycling sky → sun → coral.
6. **Proof strip** — four `Stat`s between hairlines. No card, no background.
7. **Work with me** — heading and CTA on the left, three `EngagementRow`s on the right.
8. **Footer** — warm surface, newsletter with promise line, two short link columns.

Rules the kit encodes: one yellow CTA per band, one inverted band per page, section rhythm at `--section-y`, and every image is a flat accent-coloured slot until a real photograph exists.
